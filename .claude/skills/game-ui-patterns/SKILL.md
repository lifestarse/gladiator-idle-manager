# Game UI Patterns — idle/gladiator RPG

Скилл-справочник: как выглядят и ведут себя экраны в успешных играх жанра
(AFK Arena, Idle Heroes, Nonstop Knight, Firestone Idle RPG, Gladiator Manager),
и как переносить эти паттерны на нашу Kivy-дизайн-систему, не ломая её.

## Анатомия боевого экрана idle-RPG (вертикальный мобильный)

Сверху вниз — так делают почти все игры жанра:

1. **Контекст-бар** (верх): номер этапа/тира + прогресс волны «3/10» с меткой босса
   на последней точке. Игрок всегда видит, *где* он и *сколько осталось*.
2. **Панель врагов** (верхняя треть): карточки/спрайты врагов, HP-бары красные.
   Босс выделен: крупнее/золотая рамка/собственный широкий HP-бар с именем.
3. **Центральная полоса событий**: тикер убийств/скиллов, НЕ поверх карточек.
4. **Панель своих бойцов** (нижняя треть, крупнее вражеской — «своих видно лучше»):
   HP + статус скилла (готов/кулдаун) на каждом.
5. **Панель управления** (низ, зона больших пальцев): одна доминирующая CTA
   («В бой»/Auto) + второстепенные (режим, скип). Тогглы показывают СОСТОЯНИЕ:
   auto горит когда включён, скорость подписана «x1/x2/x4».

### Стандартные элементы жанра, которых ждёт игрок

| Паттерн | Как в жанре | Зачем |
|---|---|---|
| Прогресс волны | «3/10» + пипсы, босс-скулл на 10-й | видно расстояние до награды |
| Speed toggle | x1→x2→x4 циклом, одна кнопка | уважение ко времени игрока |
| Auto-состояние | кнопка-тоггл с подсветкой, а не «выстрел» | понятно, что бой сам идёт |
| Loot-превью | что упадёт с этого врага/тира ДО боя | мотивация драться |
| Victory-сводка | модалка: золото/XP/предметы иконками + «Tier up!» | пик эмоции (Peak-End rule) |
| Boss intro | баннер/врезка на 1 сек перед боссом | событие, а не ещё одна волна |
| Best run | «Best: T12 · 340 kills» всегда на виду | соревнование с собой |
| Next unlock | «На Tier 8 откроется X» | крючок прогрессии |

### Боевой фидбек («juice») — уровни интенсивности

Обычный хит < крит < килл < победа < тир-ап. Каждый уровень заметно жирнее
предыдущего, иначе всё сливается:

- хит: флеш HP-бара + мелкая цифра урона + короткий shake (есть у нас);
- крит: цифра крупнее, золотая, с «!» (есть);
- килл: строка в тикере + серый/раненый спрайт (есть);
- победа: золотой флеш экрана (есть) + **сводка лута** (нет);
- low-HP своего бойца: пульс рамки карточки / амбер-бар (бар есть, пульса нет).

Ограничение: не больше одного полноэкранного эффекта одновременно; урон-цифры
джиттерить (уже сделано `_DMG_JITTER_DP`).

## Gap-анализ нашей арены (на 2026-07-26; перепроверь по коду!)

Уже есть (НЕ предлагать заново): карточки юнитов через RecycleView
(`ui_helpers/_arena_cell.py`), floating damage + джиттер, shake, hurt-фрейм
спрайта, тикер в разделителе, victory flash, золотая рамка босса, HP-бакеты
зелёный/амбер/красный, бейдж скилла RDY/кулдаун, Run/Tier-бар, кнопка лечения.

Отсутствует относительно жанрового стандарта (кандидаты на редизайн):

1. **Прогресс внутри тира** — `run_text` даёт «Run #1 · 0 kills», но нет полосы
   «до следующего тира/босса осталось N». Самый дешёвый большой выигрыш.
2. **Victory-сводка** — награда сейчас одна floating-строка «+250»; жанр требует
   модалку с иконками лута (спрайты предметов уже подключены — `item_icon_source()`).
3. **Speed toggle** — `BATTLE_AUTO_INTERVAL` фиксирован; x2/x3 — типовой
   idle-паттерн (и типовое место для rewarded ad).
4. **Auto как состояние** — кнопка «Auto» не показывает, что бой уже идёт
   (частично компенсировано `disabled`, но жанр рисует активный тоггл).
5. **Boss intro** — `_show_boss_revenge_popup` есть только для revenge-кейса;
   обычный босс появляется без события.
6. **Loot-превью врага** — попап врага есть (`enemypopupmixin`), но дропа там нет.
7. **Best run** — `best_text` вычисляется, но на боевом виде не показан.
8. **Low-HP пульс** карточки своего бойца.

## Привязка к нашей дизайн-системе (обязательно)

- Кнопки — только `MinimalButton` с `variant` (primary/secondary/ghost);
  цвета из `theme.*`, никаких хардкод-RGBA.
- Ряды фильтров/режимов — `ChipRow` / `build_tab_row()`, не самодельные табы.
- Бейджи состояния — `PixelBadge`; бары — `MinimalBar` (анимация `_display_value`,
  при ребинде пула гасить `Animation.cancel_all` — см. `_arena_cell.py`).
- Однострочный текст — `AutoShrinkLabel(single_line=True)`.
- PixelFont: только ASCII + кириллица, БЕЗ ⋮●○✗🔒-символов; длинные описания — BodyFont.
- Заголовок арены — English-only (PressStart2P, см. коммент в `arena/_core.py`).
- Карточки арены — pooled RecycleView viewclass: новые элементы карточки добавлять
  в `ArenaUnitCardView.__init__` + `refresh_view_attrs`, никакого состояния,
  переживающего ребинд. Анимации только на видимых виджетах через
  `find_arena_view_by_name` (офскрин — пропуск, это намеренно).
- Эффекты — расширять `arena/effectsmixin.py`, не плодить параллельные механизмы
  (тикер вместо центр-floats — уже выученный урок).
- Все строки — через `t()` + ключи в UI-JSON всех 8 языков
  (гейты `test_i18n_ui_quality.py` / `test_i18n_data_quality.py`).
- `# Build: N` инкрементить в каждом тронутом файле; перед сдачей — pytest,
  включая `test_cross_package_name_resolution`.
