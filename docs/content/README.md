# Удалённый контент

Эта папка раздаётся через GitHub Pages — там же, где `scripts-library.json` и
`privacy-policy.html`. Отсюда игра берёт **языковые пакеты** и патчи текста и
баланса, чтобы исправления доезжали до игроков без релиза в Play.

**Кода здесь нет и не будет.** Ни один файл отсюда не исполняется — только
данные. Обновление кода идёт через Play, потому что политика Play запрещает
приложению обновлять себя в обход магазина.

## Что где лежит

```
manifest.json            индекс: что есть, какой ревизии, для каких сборок
packs/<lang>.vN.json     полный языковой пакет: {"lang","revision","ui","data"}
<lang>.vN.json           патч поверх встроенного языка (только для en)
balance.vN.json          патч баланса
```

## Языковые пакеты

В APK лежит **только английский**. Остальные восемь языков — пакеты, которые
игрок скачивает: 78–95 КБ в gzip каждый, экономия в сборке ~675 КБ.

Пакет несёт сразу оба документа языка — `<lang>.json` (830 строк интерфейса) и
`data_<lang>.json` (тексты врагов, травм, лора, зачарований). Они едут вместе и
ставятся атомарно: язык, у которого интерфейс переведён, а имена врагов
английские, выглядит сломанным, и игрок не может это починить.

Порядок поиска файла — **сначала встроенное, потом пакеты**. Английский нельзя
перекрыть скачанным: он замыкает цепочку фолбэков `localization.t()`.

Пакеты обновляются целиком по номеру ревизии. Патчей для них нет намеренно —
одна механика на язык, иначе появляется вопрос «поверх какой ревизии лежит этот
патч». Патчи остаются только для встроенного английского.

## Как это работает

1. Старт читает **только локальные файлы** — встроенные и уже скачанные.
   Нет сети — нет разницы.
2. Через 6 секунд после запуска фоновый поток проверяет обновления: **если сети
   нет, проверка пропускается сразу**, без пятисекундного таймаута
   (`_net.is_online()`, на Android — через ConnectivityManager).
3. Скачанное фоном применяется **со следующего запуска**.
4. Исключение — явный выбор языка игроком: там пакет качается с прогрессом и
   применяется немедленно, потому что интерфейс в этот момент и так
   перестраивается.

## Защита

- **Валидация на клиенте.** Пакет проверяется тем же валидатором, что и патч:
  ключи обязаны быть во встроенном `en.json`, плейсхолдеры `{name}` и разметка
  `[b][color=…]` обязаны совпадать, длина ограничена. Пакет, у которого не
  выжило 90% строк, не ставится вообще — игрок остаётся на английском, который
  работает.
- **Атомарная установка.** Оба файла пишутся через `.tmp` и переименовываются;
  прерванная установка читается как «языка нет», а не как половина языка.
- **Safe-mode.** Перед применением патчей ставится маркер, снимается через
  6 секунд живого UI. Маркер на старте = прошлый запуск умер на патче, кеш
  выбрасывается. Плохой патч стоит одного запуска, а не всех установок.
- **Лимит размера — во время чтения, а не после.** Ответ читается кусками по
  16 КБ; сервер, который не объявил длину и льёт бесконечно, обрывается.
- **Гейт на min_app/max_app** и запрет абсолютных путей и `..` в манифесте.

## Публикация

Базой для патчей служит git-ref той сборки, которая **у игроков**, не HEAD.
Пакеты собираются из текущего состояния репозитория.

```
python scripts/publish_content.py --since v1.9.44 --packs all            # план: ничего не пишет
python scripts/publish_content.py --since v1.9.44 --packs uk,de --publish
python scripts/publish_content.py --since v1.9.44 --lang en --balance --publish
git add docs/content && git commit -m "content: uk pack v2" && git push
python scripts/publish_content.py --check-live   # Pages реально раздаёт то, что в docs/content?
```

По умолчанию скрипт печатает план и **ничего не пишет** — запись только по
`--publish`. Перед записью он сверяет ревизии с живым манифестом на Pages:
чекаут, отставший от опубликованного, к публикации не допускается (сначала
`git pull`). `--check-live` после пуша подтверждает деплой побайтово: «запушено»
и «раздаётся» — разные состояния, Pages собирается с лагом.

Скрипт прогоняет всё через тот же валидатор, что и устройство, и печатает, что
отклонил.

**Откат — это новая ревизия, а не старая.** Клиенты кешируют по номеру: чтобы
отменить `uk.v3`, публикуйте `uk.v4` с прежним текстом. Понижение номера ничего
не изменит у тех, кто уже забрал v3.

## Выключатель

`REMOTE_CONTENT_ENABLED = False` в `game/remote_content/__init__.py` — гасит
всю сетевую часть разом: и патчи, и загрузку новых пакетов.

Уже установленные пакеты продолжают работать: их читают `load_languages()` и
`apply_translations()` прямо с диска, без участия этого модуля. То есть
выключатель бьёт по новым установкам и по смене языка, а не по тем, кто свой
язык уже скачал. Это аварийная мера (например, если угнали GitHub-аккаунт), а
не штатный режим.
