Аудит «глазами Google-ревьюера» на 2026-07-24, код v1.9.37. Проблемы на тот момент (перед действием — **сверять с кодом**, могли быть починены):

**Статус на 2026-07-27 (сверено с кодом):** из «осталось» ЗАКРЫТЫ — миграция Billing 6→8.3.0, ревизия рекламы (KivMob → свой Java-шим, GMA 24.9.0; реклама выключена флагом `ADS_ENABLED=False`) и UMP-консент — всё в [[billing8-ads-2026-07-25]]. Всё ещё ОТКРЫТО: ротация пароля keystore (утёк в git-историю, commit 2c6fc13; инструкция `keytool` лежит комментарием в buildozer.spec), подпись/валидация IAP и лидербордов, broad except (сейчас 113 строк `except Exception` в game/), вранье в docs (ARCHITECTURE/API/BALANCE/GDD — см. PROJECT_MAP «несоответствия»).

**Статус фиксов (2026-07-24, ветка `claude/fix-found-issues-c82bed`, v1.9.38):** исправлены кодовые пункты — IAP-стаб (free purchase), rewarded-стаб (free reward), durability сейва (load fallback primary→.tmp→.bak, copy-ротация .bak, fsync, quarantine в .corrupt), `_load_failed` подключён (+ блок сейва после битых cloud-данных), in-place `ACHIEVEMENTS`, `engine.state_lock` (RLock: interpreter-ops / idle_tick / battle_* / _build_save_data), тосты `save_failed_toast`/`save_blocked_toast` (все 9 языков), лимит 2 МБ + RecursionError в online_library, пароль keystore удалён из buildozer.spec (подпись через env P4A_RELEASE_*). **Осталось (нужны решения юзера):** ротация пароля keystore (утёк в git-историю, commit 2c6fc13), миграция Billing 6→8 до 31.08.2026, ревизия рекламы (KivMob несовместим с Ads SDK v20+, в spec оставлен комментарий), подпись/валидация IAP и лидербордов, UMP-консент, 16× broad except, вранье в docs.

**Блокеры релиза / потеря денег и данных:**
- `game/iap/_core.py:42` — ветка stub `if not self._initialized: on_success()` стоит до проверки платформы → на Android при неподключённом биллинге товар выдаётся бесплатно.
- `game/ads.py:117` — rewarded при реальном REWARDED_ID и `not _initialized` выдаёт награду без показа рекламы. Плюс Ads SDK (kivmob/play-services-ads) **не объявлен** в `buildozer.spec:10,35` → реклама в проде мертва.
- IAP-покупки без проверки подписи (`getSignature`/RSA) и без сервера → спуф на рутованном устройстве.
- `game/engine/persistencewritemixin.py:97-106` + `persistencereadmixin.py:11-15` — двухшаговая ротация (primary→.bak, tmp→primary); при убийстве процесса между ними primary отсутствует, а `load()` при отсутствии primary делает fresh start и **не читает .bak** → потеря всего прогресса.
- Читерство лидербордов: сейв — неподписанный plaintext JSON, `submit_all` шлёт `best_record_tier/total_wins` в Play Games без валидации (`game/engine/_core.py:231`, `leadersubmitmixin.py`).
- **Пароль release-keystore в открытом виде** в `buildozer.spec:53-54`, закоммичен (commit 2c6fc13), репозиторий github.com/lifestarse/gladiator-idle-manager **публичный**. Сам keystore-файл в git не попадал.

**Политика Google Play (дедлайны):**
- Billing 6.2.1 → с 31 авг 2026 обновления требуют v8+ (миграция 6→7→8).
- `android.api = 35` — ок для обновлений существующего приложения; новые приложения с 31 авг 2026 требуют API 36.
- Нет UMP/GDPR consent-флоу при заявленном `AD_ID` (`buildozer.spec:25`).

**Надёжность/корректность:**
- `run_on_demand_async` (`game/scripting/manager.py:358`) исполняет интерпретатор в daemon-потоке, мутирует engine.gold/inventory/fighters/battle_mgr и вызывает save() без локов против главного потока → гонки, битый сейв.
- `_load_failed` (`persistencewritemixin.py:110,143`) читается, но **нигде не ставится в True** — «защита от перезаписи после failed load» мёртвая.
- `wiringmixin.py:62` **ребиндит** `_ach_module.ACHIEVEMENTS` вопреки in-place контракту; lore-экран (`statsquestsmixin.py:88`) держит захваченную ссылку на хардкод-список → `total_ach` показывает **29** вместо **50** из JSON.
- Тихие отказы сейва: `save_async` глотает исключение в лог, `save()` без try/except; юзеру «не сохранилось» не сообщается.
- 16 мест `except Exception: pass` при правиле CLAUDE.md «конкретные except».

**Мелочи:** `online_library.py` без лимита размера ответа/глубины AST; `ui_config.json` не читается кодом; docs (ARCHITECTURE/API/BALANCE/GDD) описывают домонолитную раскладку и врут по фактам (см. PROJECT_MAP.md раздел «несоответствия»); cloud без refresh токена при 401.

**Хорошо:** AST-песочница скриптов (whitelist `_kind`, лимиты интерпретатора), TLS с certifi везде (нет verify=False), атомарная запись через os.replace, `.corrupt`-карантин битого сейва, 400+ тестов, `test_name_resolution.py`.
