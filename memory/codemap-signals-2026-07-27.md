Аудит структуры по `codemap/` 2026-07-27. Три сигнала из семи оказались ложными — все три
из-за особенностей самого генератора. **Проверяй по коду, прежде чем чинить.**

**`# Build: N` — НЕ счётчик правок.** При сплите файла номер наследуется от родителя.
`game/app/_shared.py` показывает Build 66 и выглядит самым горячим файлом проекта, а по
`git log --follow` у него **5 коммитов**: 61 достался от `main.py` на Wave-3 сплите
(`git show c5ef677^:main.py` → `# Build: 61`). Настоящий топ по churn совсем другой:
`main.py` 22, `buildozer.spec` 22, `game/engine.py` 19, `gladiatoridle.kv` 16. Любая
эвристика «высокий Build = нестабильность» сломана для каждого файла, рождённого при сплите.

**Фантомные циклы на `from . import X`.** Генератор вешает такое ребро на узел **пакета**, а
`__init__.py` импортирует сабмодуль обратно — получается SCC на ровном месте. Так
`game/scripting` репортился циклом из 7 узлов; на деле граф сабмодулей чистый DAG, и
`errors.py` действительно лист, разрывающий настоящий цикл (как и написано в PROJECT_MAP.md).
Подтверждено 14 импортами в свежих подпроцессах — хрупкости порядка нет. **Чинить надо
генератор** (резолвить `from . import X` в `package.X`), иначе фантом будет вылезать на любом
корректном пакете.

**«Артефакт не упомянут в коде» ≠ мёртвый.** Связи строятся по литеральному упоминанию имени
файла (`scripts/gen_codemap.py:8-11`). `data/languages/data_*.json` (1.27 МБ) грузятся
вычисляемым путём — `translationmixin.py:23` делает `resolve(f"data_{lang_code}.json")`. Они
живые: входные данные для сборки паков (`scripts/publish_content.py:140-146`) и **уже
исключены** из APK строкой в `buildozer.spec:18`. Асимметрия ru/uk — просто буквальное
упоминание в одном тесте и одном комментарии.

**Что сигналы показывают честно:** направление зависимостей (ядро → UI пусто), реальные
циклы module-level импортов (см. [[import-cycles]]), fan-in/fan-out, размерные выбросы внутри
пакета. Но помни: **лимит на размер файлов снят 2026-07-25**, поэтому большой файл сам по
себе не дефект — нужна конкретная цена. `cells.py` на 1050 строк связный и стабильный
(2 коммита за 14 месяцев); настоящая проблема пакета `game/screens/scripts/` не в размере, а
в том, что он остался вне `game/ui_helpers/` и без единого теста.
