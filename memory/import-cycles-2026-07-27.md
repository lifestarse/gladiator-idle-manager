Было 4 цикла импортов, каждый держался только на ленивых импортах внутри функций.
2026-07-27 разорваны три (коммит `refactor(imports): break 3 of the 4 import cycles`).

**Оставшийся цикл `game.localization ↔ game.remote_content` — намеренный.** Это
задокументированный с обеих сторон протокол `patch_language()`. Не «чинить».

**Главная ловушка (стоила отдельного расследования).** Очевидный приём «импортировать
не пакет, а его сабмодуль» — `from game.battle._types import BattleEvent` вместо
`from game.battle import ...` — **не развязывает зависимость**. Python при импорте
сабмодуля сначала целиком выполняет `__init__.py` родительского пакета, так что
подтягивается весь пакет вместе с модулем, который импортирует обратно. Взаимная
зависимость остаётся, но становится **зависимой от порядка**: работает при входе через
один модуль и падает `ImportError: partially initialized module` при входе через другой.
Это «ложный зелёный» — SCC-детектор по codemap перестаёт видеть цикл, а хрупкость
растёт. Правильно было перенести модуль внутрь пакета (`game/boss_modifiers.py` →
`game/battle/_boss_modifiers.py`).

**Как искать циклы:** `python scripts/gen_codemap.py`, затем Тарьян по рёбрам из секций
«## Импортирует» в `codemap/*.md`. Учти: codemap строится по AST и **видит импорты
внутри функций тоже**. Отдельно полезно строить граф только по module-level рёбрам —
это то, что реально ломается на старте.

**Тест-стража** в `tests/test_imports.py`: AST-проверка на прямой импорт
`game.base_screen` из `game/ui_helpers/*`, плюс проверка в свежем субпроцессе, что
`import game.ui_helpers` не подтягивает `game.base_screen` транзитивно (AST ловит только
прямое ребро). Проба чувствительна: `game.screens.arena` даёт True, `game.ui_helpers` —
False. Не ослаблять — см. также [[engine-scripting-split-2026-07-24]].

`_needs_rebuild` живёт в `game/ui_helpers/_layouts.py` рядом со своей парой
`_invalidate_grid_cache`; `BaseScreen` привязывает его как `staticmethod`. Обычная
функция, присвоенная в теле класса, стала бы связанным методом и молча получила бы
`self` первым аргументом — на это есть тест на идентичность объекта.
