# Арена + уровень игрока (2026-07-27)

Не влито, лежит в рабочем дереве. 702 теста зелёные, смоук-запуск чистый.

## Что сделано

**Арена** (по gap-анализу `.claude/skills/game-ui-patterns`): FIGHT↔STOP-тоггл,
скорость x1/x2/x4 (`engine.battle_speed`, персист + кламп), victory-банер,
tier-up попап, boss-intro банер (движок слал `boss_intro` всегда — UI игнорировал),
полоса погони за рекордом, превью награды, defeat-флеш, low-HP подсветка карточек.

**Уровень игрока**: `player_level` / `player_xp` на движке, методы в
`game/engine/_progression.py`, таблица `FEATURE_UNLOCKS` в `game/constants.py`.
XP из четырёх точек: победа на арене (масштаб по тиру), убийство босса,
экспедиция, ачивка. Уровень **переживает roguelike_reset** — ран умирает,
аккаунт нет.

## Геймдизайн-решения юзера (не менять без него)

- **«Все с нуля»** для старых сейвов. Юзеру было озвучено, что ветеран с T20
  потеряет доступ к скриптам и экспедициям до докачки — выбрал осознанно.
  Поэтому в `persistencereadmixin` НЕТ вывода уровня из прогресса.
- **Скрипты открываются последними** (ур. 15, максимум таблицы). Есть тест
  `test_scripts_are_the_last_unlock`, который ловит правку таблицы.
- **Побег со штрафом**: `stop_auto_battle` возвращает накопленное в бою золото.
  Причина — `award_gold` платит за каждое убийство по ходу боя, поэтому без
  штрафа STOP был бы безрисковым эксплойтом. Пожизненный `total_gold_earned`
  намеренно НЕ откатывается (иначе задним числом разжигаются ачивки).
- **Бэкенд — Play Games Services**, не Firebase и не свой сервер.

## Грабли, найденные ревью

- Тап по STOP может долететь ПОСЛЕ того, как `_check_battle_end` снял
  `is_fighting` (Kivy тикает Clock до dispatch_input). Отсюда
  `BATTLE_END_TAP_GUARD`. Тот же класс багов ждёт любую кнопку-тоггл,
  состояние которой меняет Clock-колбэк.
- Kivy `Popup` — оконный, а бой продолжается после ухода с экрана: модалка
  вылезала поверх кузницы. Отсюда `_pending_tier_up` + показ на `on_enter`.
- У чистого `GameEngine` в тестах **нет бойцов и нет preview_enemies** —
  `start_auto_battle()` молча не стартует. Нужна фикстура с
  `fighters.append(Fighter(...))` + `_spawn_enemy()`, см. `fighting_engine`
  в `tests/test_battle_speed.py`.
