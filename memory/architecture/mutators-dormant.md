`data/mutators.json` (20 записей, переведены на 8 языков) и `game/mutators.py` (calc_reward_multiplier / has_effect / get_effect_value) — **спящий контент**: ни одна функция не вызывается, UI мутаторы нигде не показывает, `engine.active_mutators` всегда `[]` (сохраняется/читается, но не наполняется). Это НЕ забытый баг: по docs/GDD.md §8–9 мутаторы — часть prestige-системы (анлок на prestige 1, слоты на 5/15, выбор на старте рана), а prestige в коде не существует вовсе (grep: только в docs).

**Решение юзера 2026-08-03: оставить спящими.** Данные инертны (в рантайме никому не мешают, игроку не видны), переводы уже оплачены и пройдут пригодятся при достройке prestige. Не подключать эффекты без всей цепочки (анлок → UI выбора → применение в бою/экономике/хиле/экипировке), не выпиливать данные и переводы.

Полный аудит кода 2026-08-03 (229 файлов, агент на файл + опровергатели, scratch/audit_report.md) прочие подтверждённые находки закрыл — коммиты bc1984e (сами правки; осторожно: этот коммит битый сам по себе, чинится следующим) и 20988f3-выравнивание (докоммичен рефакторинг прошлой сессии, HEAD самосогласован). Урок про «коммить связанные файлы вместе»: constants.py и его потребители из разных волн работы должны ехать одним коммитом.
