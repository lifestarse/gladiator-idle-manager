Сделано 2026-07-27 (v1.9.46+, ветка влита в master). Расширение [[remote-content-overlay]].

**Что теперь можно без релиза:** опубликовать новый язык (`scripts/publish_content.py --packs tr --name "tr=Türkçe" --font tr=<path.ttf>` + git push в `docs/content/`) — он появится в пикере у уже установленных клиентов. Раньше мешали две захардкоженные вещи: `packs.OFFERED` (список пикера) и шрифт в APK.

**Ключевое решение — шрифты хранятся content-addressed:** имя файла в `<packs>/fonts/` = его собственный sha256. Удалённая сторона НЕ выбирает имя файла. Это разом снимает: коллизию двух языков с одинаковым published-именем, «отравление» чужого шрифта при ротации, и путь-инъекцию через имя. GC удаляет файлы, на которые не ссылается `.fonts.json`.

**Инвариант:** пак не ставится без своего шрифта (`download()` тянет шрифт первым). Язык, который рендерится квадратиками, хуже английского.

**Точка подключения шрифта — `localization.set_language()`**: единственный чокпоинт, который проходят все три потока активации языка (восстановление сейва в `engine.load()`, докачка пака на старте, переключение во вкладке More — последний НЕ вызывает `_apply_language_now`, у него своя копия последовательности). Переригистрирует Kivy-алиасы `PixelFont`/`BodyFont` (оба — скрипт, который пиксельный шрифт не тянет, не может оставить пиксельный шрифт нигде).

**Манифест теперь недоверенный вход для имён файлов.** Суффикс `lang.*`/`pack.*` — это код языка, который становится именем файла (`<code>.json`), поэтому в `_manifest.validate` он ограничен `[a-z0-9_-]{1,16}`. Без этого `"pack.../.gladiator_idle_save"` рулил бы записью/удалением вне каталога паков (нашёл адверсариальный ревью, было реально воспроизводимо). Там же: путь шрифта обязан иметь непустой basename (`"fonts/"` → `""`), проверка по обоим разделителям.

**Грабли, стоившие времени:**
- `http.client.IncompleteRead` НЕ наследует `OSError`/`URLError` — пролетала мимо `except` в `_http`, убивала воркер-тред и намертво вешала строку пикера. Ловить `http.client.HTTPException`.
- `import kivy` **парсит sys.argv** и печатает usage/выходит на чужих флагах. Поэтому `game/storage.py` определяет Android по env `ANDROID_ARGUMENT` (то же, что проверяет `kivy.utils.platform`), а не импортом Kivy — иначе `scripts/publish_content.py --since ...` падал с kivy-usage. Любой headless-скрипт, тянущий `game.localization`, ломается об это.
- Поиск шрифта в `set_language` не имеет права бросать: он внутри `engine.load()`, у которого blanket-except → **карантин здорового сейва** и потеря прогресса.

Гейт покрытия глифов есть в двух местах: `tests/test_font_glyph_coverage.py` (только для языков в `data/languages/`) и в паблишере (`check_glyph_coverage`) — для manifest-only языков, которые в репо не попадают вообще. Тесты фичи: `tests/test_remote_fonts.py`.
