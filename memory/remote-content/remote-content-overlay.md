`game/remote_content/` — доставка языков и исправлений баланса **без релиза в Play**.
Сделано 2026-07-26 по запросу юзера.

**Кода не качает и не исполняет — только JSON.** Политика Play запрещает приложению
обновлять себя в обход магазина. Это решение, а не недоделка — не «улучшать» до горячей
загрузки Python.

## Языковые пакеты (решение юзера 2026-07-26)

**В APK лежит только `en.json`.** Остальные 8 языков — скачиваемые пакеты. Исключение
прописано в `buildozer.spec` (`source.exclude_patterns`), экономия ~675 КБ, пакет
78–95 КБ в gzip.

Пакет несёт **оба** документа языка сразу: `<lang>.json` (830 строк UI) и
`data_<lang>.json` (тексты врагов/травм/лора/зачарований). Ставятся атомарно — язык с
переведённым интерфейсом и английскими именами врагов выглядит сломанным.
`is_installed()` требует оба файла, поэтому прерванная установка читается как «нет языка».

Порядок поиска — **встроенное, потом пакеты** (`packs.resolve`). Английский нельзя
перекрыть: он замыкает цепочку фолбэков `t()`. Есть тест на это.

Пакеты обновляются **целиком по ревизии**, патчей для них нет намеренно: одна механика на
язык, иначе появляется вопрос «поверх какой ревизии лежит патч». Патчи остались только
для встроенного английского.

**Что пришлось поменять из-за этого:**
- `set_language()` падал обратно на `"ru"`, которого в сборке больше нет → теперь на `"en"`.
- `load_languages()` читает из двух директорий и **пропускает `data_*.json`**. Раньше они
  парсились в `_LANG_DATA` на каждом старте (~2 МБ) и `t()` их никогда не читал.
- Возвращающийся игрок: в сейве записан язык, которого в новом APK нет. Без обработки
  апдейт выглядит как поломка. `applocalemixin._ensure_saved_language_present()` качает
  пакет с прогрессом **до** показа игры; без сети — работает на английском и повторит
  на следующем запуске.

## Два свойства, на которых держится конструкция

1. **Оверлей/фолбэк, не замена.** Английский всегда в APK и всегда валиден. Патч может
   только переписать существующий ключ. Совместимость в обе стороны бесплатно.
2. **Скачанное фоном применяется со СЛЕДУЮЩЕГО запуска.** Старт читает только диск.
   Исключение — явный выбор языка игроком: там применяется сразу, потому что UI в этот
   момент и так перестраивается (решение юзера).

**Safe-mode:** маркер `~/.gladiator_content_applying` ставится перед применением, снимается
через 6 секунд живого UI (`Clock.schedule_once` в `game/app/_core.py` — не инлайном в конце
`build()`, иначе заверяли бы патч, падающий на первом кадре). Маркер на старте = прошлый
запуск умер под патчем → кеш выбрасывается.

## Точки врезки (не переносить)

- `game/localization.py` `load_languages()` — две директории, скип `data_*`, затем
  `patch_language()`.
- `game/data_loader/_core.py` `load_all()` — `patch_gamedata()` **после сырых загрузок, но
  до `_build_tier_index`**: патч тира врага должен попасть в индекс.
- `game/data_loader/translationmixin.py` — `packs.resolve(f"data_{lang}.json")`.
- Импорты **ленивые**: `remote_content` читает `flatten`/`set_path` из `localization`, а
  `localization` автозагружается при импорте и зовёт обратно. Проверено в обоих порядках.

## Валидация

Текст: ключ обязан быть во встроенном файле, плейсхолдеры и BBCode совпадают, длина
≤ max(4× встроенной, 40 символов). Пакет, у которого не выжило 90% строк, не ставится.
Баланс: белый список секций и полей с диапазоном на каждое, `bool` отвергается явно (он
подкласс `int`, `True` стал бы ценой 1), нельзя добавить запись или поле.
`test_whitelist_fields_exist_in_the_real_data_files` сверяет белый список с реальными
файлами. **Врагам патчится только `tier`** — статов у них нет, они выводятся из
tier/role/stat_bias.

Транспорт `_http.fetch_json` читает **кусками по 16 КБ** и держит лимит во время чтения,
а не после; отдаёт прогресс через `on_bytes(received, total)`, `total=None` если сервер не
объявил длину → UI показывает неопределённый индикатор, а не выдуманный процент.
Заглушки в тестах должны истощаться и иметь `.headers`, иначе это не HTTP-ответ.

## UI

`game/ui_helpers/_language_picker.py` — **один** виджет для первого запуска и для экрана
«Ещё» (раньше оба держали свою копию списка языков). Статус на каждом языке, реальный
прогресс-бар, загрузка в daemon-треде, все касания виджетов через `Clock.schedule_once`.
13 ключей `lang_status_*` / `lang_stage_*` / `btn_continue_english` добавлены во все 9
языков — гейт требует полного покрытия.

## Публикация

`python scripts/publish_content.py --since <ref релиза> --packs all|uk,de --lang en --balance`
Результат в `docs/content/` (GitHub Pages). Скрипт гоняет через тот же валидатор, что и игра.
**Откат — новая ревизия, а не старая**: клиенты кешируют по номеру.

Выключатель `REMOTE_CONTENT_ENABLED = False` гасит сеть, но уже установленные пакеты
продолжают читаться с диска.

Связано: [[i18n-ui-quality]] (что именно доставляем), `docs/content/README.md`.
